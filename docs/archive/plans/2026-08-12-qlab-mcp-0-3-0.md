# QLab MCP 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the current QLab MCP surface into a coherent 0.3.0 release with exactly 13 public FastMCP tools, truthful current documentation, portable CI, audited workorders, and no unnecessary architecture refactor.

**Architecture:** Keep the internal `QLabReader.update_cues` implementation and the canonical `qlab_edit_cues` route. Remove only the public `qlab_update_cues` FastMCP registration and its compatibility metadata. Treat `.codex/agents/` as local development infrastructure, install `uv` in CI because the existing packaging test invokes it, and record the architecture audit without extracting modules unless a safe, obvious boundary is found.

**Tech Stack:** Python 3.11+, FastMCP 3.x, Pydantic 2.x, pytest, uv, Hatchling, GitHub Actions.

## Global Constraints

- Release version is exactly `0.3.0` in `pyproject.toml`, `src/qlab_mcp/__init__.py`, `uv.lock`, package tests, and current user documentation.
- The public MCP inventory is exactly 13 tools and contains `qlab_edit_cues`, never `qlab_update_cues`.
- Preserve the existing dry-run, exact-target, confirmation-token, fresh-readback, and rollback safety contracts.
- Do not rename or remove internal `QLabReader.update_cues` methods used by the write stack.
- `.codex/agents/` remains ignored local infrastructure; do not add those files to the release or CI checkout.
- Historical evidence under `docs/archive/` remains historically accurate; do not mass-rewrite archived references to the former alias.
- No QLab runtime mutation is part of this release-preparation work.

### Task 3: Make CI reproducible on a clean runner

**Files:**
- Create: `.github/workflows/python-app.yml`
- Modify: `tests/test_agent_skill_bindings.py`

**Interfaces:**
- Consumes: Python package metadata, `uv.lock`, and the existing pytest/packaging tests.
- Produces: a CI job that runs without ignored `.codex/` files and with the `uv` executable required by packaging tests.

- [ ] **Step 1: Reproduce the clean-checkout failures**

Run the agent-binding tests from a `git archive` checkout and run packaging with `PATH` excluding `uv`. The expected failures are missing `.codex/agents/*.toml` and `FileNotFoundError: [Errno 2] No such file or directory: 'uv'`.

- [ ] **Step 2: Make local-agent tests conditional**

Add `pytest` to `tests/test_agent_skill_bindings.py` and skip the two tests when the required ignored files are absent:

~~~python
import pytest

AGENT_FILES = (
    ROOT / ".codex/agents/qlab-docs-researcher.toml",
    ROOT / ".codex/agents/fastmcp-mcp-researcher.toml",
)
pytestmark = pytest.mark.skipif(
    not all(path.is_file() for path in AGENT_FILES),
    reason="project-local .codex/agents fixtures are not part of the repository",
)
~~~

When the files exist locally, the assertions continue to protect the local agent setup; on CI they are reported as skipped rather than failed.

- [ ] **Step 3: Add the minimal GitHub Actions workflow**

Create `.github/workflows/python-app.yml` with Python 3.11, read-only repository permissions, editable package installation, an explicit `python -m pip install uv`, and the full suite:

~~~yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

jobs:
  tests:
    name: pytest
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          python -m pip install uv
          python -m pip install -e ".[dev]"
      - name: Run test suite
        env:
          PYTHONDONTWRITEBYTECODE: "1"
        run: pytest -q -p no:cacheprovider
~~~

The workflow must not copy or generate `.codex/agents/` files.

- [ ] **Step 4: Verify the clean checkout locally**

Run the archived checkout with the real local `uv` available and confirm the agent tests skip while packaging can build. Run the full repository suite in the normal checkout separately; socket-binding failures caused only by the managed sandbox must be recorded as environment failures, not product failures.

- [ ] **Step 5: Commit the CI fix**

~~~bash

git commit -m "ci: make clean runner checks reproducible"
~~~
