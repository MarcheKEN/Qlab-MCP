- cue type: `Video`
- profile: `video_basic`
- cue ref: exact cue UUID only
- property: `videoEffectIndex/parameter`
- effect index: `0`

## Investigation answers

1. Documented OSC setter by index: yes. QLab documents
   `/cue/{cue_number}/videoEffectIndex/{index}/parameter/{parameterKey} {setting}`.
2. Documented readback for same parameter: yes. The same path without `setting`
   returns the current parameter value.
3. Project reads exact field from QLab 5.5.10 flat payload: yes. Phase 4A
   preserves flat `videoEffects` payloads and treats `inputRadius` as a
   parameter-like scalar.
4. Fresh deterministic baseline: yes for this gate only. The dry-run and real
   preflight read uncached `videoEffects`, require index `0`, require
   `inputRadius`, require finite numeric baseline, and hash the raw effect
   payload.
5. Deterministic rollback: yes by new dry-run only. The rollback must request
   the previous numeric value and use a new token bound to the then-current raw
   payload.
6. Stable effect index: acceptable only for one immediate operation. The token
   binds index `0` and the raw effect payload hash; any add/remove/reorder or
   parameter drift makes the token stale.
7. Token binds exact context: yes. Payload includes workspace UUID, cue UUID,
   cue type, profile, effect index, parameter key, OSC setter path, requested
   value, baseline value/hash, raw effect payload hash, saved mode, operation
   kind, risk tier, and capability gate.
8. Wrong effect index/parameter/type/value rejected before setter: yes.
9. `/videoEffects/live` remains blocked: yes. Saved mode is required; `/live`
   is never generated by this gate.
10. Non-scalar, color, structured, name-based, enabled, aggregate, and
    multi-effect operations remain blocked for real writes: yes.

## Must stay blocked

- Text FX real writes
- effect targeting by name
- duplicate/ambiguous effect name targeting
- enabled/disabled effect writes
- adding/removing/reordering effects
- color parameters
- structured parameters
- enum/string parameters
- `/videoEffects/live`
- aggregate `videoEffect/*/parameters`
- raw OSC
- stage/route/surface/video input/camera patch/workspace video settings
- `fileTarget`, warping/control points, playback/GO/audition/stop/panic
- any broader Video FX real write support

## Future candidates only

- Camera/Text FX only after separate proof
- enabled/disabled only after stable readback
- color and structured parameters remain blocked
